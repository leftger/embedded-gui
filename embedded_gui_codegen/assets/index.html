Conversion of source art into the forms embedded-gui draws.

Both the include_gui! macro and the Studio preview call into here, which is what keeps a design’s preview and its firmware output byte-identical. Nothing in this module decodes container formats: callers hand over raw RGBA8 or file text, so the crate stays dependency-free.
