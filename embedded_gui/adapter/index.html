Output boundary color conversion adapters for [DrawTarget].

This module provides ColorConvertedDrawTarget and DrawTargetColorExt, allowing UI rendering pipelines that produce one pixel color format (such as Rgb565) to draw directly into physical display drivers or buffers that require a different native format (such as Bgr565, Rgb888, Gray8, or BinaryColor) with zero-heap, on-the-fly conversion.
